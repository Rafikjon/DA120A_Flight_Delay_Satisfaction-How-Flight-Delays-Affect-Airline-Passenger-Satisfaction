# Cost Management Plan

## 1. Approach
This is an academic project with no real budget. Costs are estimated as if the project were delivered for a client, using an assumed labour rate of **€20/hour**. Software and data costs are zero because only open-source tools, student licences and a public dataset are used.

## 4. Cost control
- Hours are tracked per task in the README log.
- Progress is reviewed weekly against the Gantt chart; if a phase exceeds its estimate by more than 20%, the team re-plans scope (e.g., the optional dashboard is dropped before core analysis).
- The contingency reserve covers rework such as additional cleaning or a second modelling iteration.
- If a fourth team member joins, hours are redistributed; the total budget stays the same.
